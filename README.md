# Братство Чворо — сајт (основа)

Статички сајт: чист HTML/CSS/JS, без базе и сервера. Хостовање бесплатно
(Netlify, Cloudflare Pages, GitHub Pages). Ово је **костур** — визуелни идентитет,
све секције и распоред су готови; остаје да се убаци стварни садржај на већ
означена мјеста.

## Структура

```
index.html          Насловна (хероj са грбом)
o-bratstvu.html     О братству / обиљежја (значење грба)
istorija.html       Историја (временска оса)
galerija.html       Галерија (lightbox)
stablo.html         Породично стабло (FamilyEcho — већ повезано)
vijesti.html        Вијести (спремно за Decap CMS)
podrska.html        Подршка / донације (рачун + Вибер)
css/style.css       Стилови (палета изведена из грба)
js/main.js          Мени, lightbox, копирање, анимације
assets/             Грб у више величина + favicon
images/             Овдје иду фотографије за галерију
build.py            (опционо) генератор страница — да заглавље/подножје остану усклађени
```

## Шта још треба убацити (означено са ✎ или 〈…〉 у фајловима)

1. **Вибер линк** — у `index.html` и `podrska.html` нађи `data-viber` и замијени
   `href="#"` стварним линком групе.
2. **Подаци рачуна** — у `podrska.html`: IBAN, SWIFT/BIC, прималац, банка.
   Не заборави и `data-copy="..."` на дугмадима „Копирај".
3. **Текст** — уводни текст (насловна), текст о братству (`o-bratstvu.html`),
   историја (`istorija.html`).
4. **Фотографије** — стави слике у `images/` па у `galerija.html` замијени
   празна поља обликом:
   ```html
   <a href="images/slika1.jpg" data-lightbox data-alt="Опис слике">
     <img src="images/slika1.jpg" alt="Опис слике">
   </a>
   ```

Породично стабло (FamilyEcho) је **већ повезано** — ништа не треба.

## Објављивање (deploy)

Најлакше: иди на app.netlify.com → „Add new site" → „Deploy manually" →
превуци цијели овај фолдер. Добијеш адресу одмах. За свој домен се веже касније.

## Вијести преко админа (касније)

Секција „Вијести" је спремна да се закачи на **Decap CMS** — једноставан админ
гдје нетехнички човјек уноси наслов, текст и слике кроз форму и клика „Објави",
без кода. То се додаје у сљедећем кораку.

## Регенерисање страница (опционо)

Ако мијењаш заглавље/навигацију на једном мјесту: измијени `build.py` и покрени
`python3 build.py` — све стране се поново исписују усклађено. Ако ти ово не треба,
слободно уређуј `.html` фајлове директно.
