# Братство Чворо

**Романија · 1790**

Сајт породичног братства Чворо са Романије - грб, историја, родословно стабло, галерија и вести на једном месту.

</div>

---

## О пројекту

Године 1790. тројица браће дошла су на Романију и започела лозу из које је израсла једна од најбројнијих фамилија сарајевско-романијског краја. Сајт постоји да то памћење не остане само по кућама и свескама, него да буде доступно свакоме ко носи презиме или трага за кореном.

Направљен је као **једна страница** кроз коју се пролази од грба до данашњих вести. Чист HTML, CSS и JavaScript - без базе, без сервера, без библиотека за приказ. То значи да ће радити и за двадесет година, и да хостовање не кошта ништа.

Кључна одлука: **садржај се мења без дирања кода.** Вести се пишу кроз админ панел на `/admin`, слике се убацују у фолдер. Ко год да наставља, не мора да зна ни ред HTML-а.

## Шта сајт садржи

| Дeo | Садржај |
|---|---|
| **Обележја** | Значење сваког дела грба - Свети Лука као крсна слава, Романија са вуком, укрштене пушке, крст цара Славе, храстов венац, лента са годином |
| **Историја** | Порекло братства и временска оса кроз генерације |
| **Галерија** | Фотографије са окупљања, са lightbox приказом |
| **Родословно стабло** | Уграђено стабло са FamilyEcho платформе |
| **Вести** | Обавештења која се уносе кроз админ панел (`/admin`) |
| **Подршка** | Рачун за донације са дугметом за копирање IBAN-а и Вибер контактом |

## Технологије

`HTML5` · `CSS3` · `JavaScript` (без библиотека) · `Decap CMS` · `Netlify Identity` · `FamilyEcho`

Сајт остаје статичан за посетиоце - мени, lightbox, копирање, анимације су писани ручно. Једина build обавеза постоји за вести: при сваком објављивању, мали Node скрипт (`scripts/build-vesti.js`) претвара фајлове из `content/vesti/` у `vesti.json`, који `js/vijesti.js` учитава на страници.

## Структура

```
.
├── index.html          # цео сајт: све секције, стилови и садржај
├── admin/               # Decap CMS админ панел (/admin) - логовање и форма за вести
│   ├── index.html
│   └── config.yml
├── content/vesti/       # по један .md фајл по вести (пише их админ панел)
├── scripts/
│   └── build-vesti.js   # генерише vesti.json из content/vesti/ при build-у
├── vesti.json           # генерисан фајл - вести које чита сајт (не уређуј ручно)
├── js/
│   ├── main.js         # мени, lightbox, копирање IBAN-а, анимације
│   ├── galerija.js     # списак фотографија
│   └── vijesti.js      # учитава и приказује vesti.json
├── assets/             # грб у више величина, favicon
├── slike/              # фотографије за галерију и слике из вести
├── netlify.toml         # build команда за Netlify
└── *.html              # преусмерења са старих адреса на секције
```

Странице попут `istorija.html` и `podrska.html` остале су као преусмерења ка одговарајућој секцији, да раније подељени линкови и даље раде.

## Како се додаје садржај

### Вест

Вести се уносе кроз админ панел на `/admin`, уз пријаву налогом који је администратор сајта одобрио (Netlify Identity). Уредник попуни наслов, текст, датум и слику, искључи опцију „Нацрт" и објави - без отварања кода. Панел сам комитује промену у GitHub, а Netlify при том build-у покреће `npm run build` који освежава `vesti.json`.

### Фотографија

1. Убаци фајл у фолдер `slike/` - малим словима, без размака и квачица (`slava-2025.jpg`, а не `Слава 2025.jpg`).
2. У `js/galerija.js` допиши ред:

```js
{ f: "slava-2025.jpg", opis: "Слава Свети Лука 2025." },
```

3. Сачувај и пошаљи на GitHub - може и кроз сам сајт GitHub-а, без икаквог програма.

## Покретање

```bash
git clone https://github.com/Cvoki/sajt_bratstva.git
cd sajt_bratstva
```

Отвори `index.html` у прегледачу - за преглед вести локално, прво генериши `vesti.json`:

```bash
npm install
npm run build
python3 -m http.server 8000
# па отвори http://localhost:8000
```

Админ панел (`/admin`) ради само на правом Netlify deploy-у (треба му Identity + Git Gateway), не и локално.

## Хостовање

Сајт је статичан и хостован на **Netlify**. Повежи спремиште и свака измена се објављује сама, обично за минут.

## Подешавање админ панела (једном, у Netlify контролној табли)

Ово су кораци које треба урадити ручно у Netlify-ју - не могу се урадити кроз код:

1. Повежи Netlify сајт са овим GitHub спремиштем.
2. **Site settings → Identity → Enable Identity.**
3. **Identity → Registration → Invite only** (да се нико сам не пријави као уредник).
4. **Identity → Services → Enable Git Gateway.**
5. **Identity → Invite users** - позови стварног уредника имејлом; добија линк за постављање лозинке.
6. Провери на `/admin` да пријава и објава вести раде пре него што се стари начин угаси.

## Плаћање картицом

Поред IBAN-а, сајт има спреман (али неактиван) начин плаћања картицом преко WSPay-а - активира се уносом приступних података у Netlify. Детаљно упутство: [`docs/PAYMENTS.md`](docs/PAYMENTS.md).
