Овдје иду слике за галерију (JPG или PNG).

Како додати слику:
1) Убаци фајл у овај фолдер (нпр. slava-2025.jpg).
2) Отвори js/galerija.js и допиши ред:
   { f: "slava-2025.jpg", opis: "Слава Свети Лука 2025." },
3) Сачувај и пошаљи на GitHub (или Commit преко GitHub сајта).

Савјет: користи мала слова, без размака и квачица у називу фајла
(нпр. okupljanje-2024.jpg, а не "Окупљање 2024.jpg").
